## ✨ Sobre o jogo

**Jogo Super Legal** é um RPG de ação com visão de cima, feito com HTML, CSS e JavaScript. Explore diferentes regiões, converse com NPCs, lute contra inimigos e chefes, e evolua seu personagem.

### 🗺️ O que você vai encontrar

- 🌴 **Três ilhas** para explorar, com diferentes regiões e desafios.
- ⚔️ **Combate e progressão**, com níveis, vida e espadas cada vez mais poderosas.
- 📜 **Missões** oferecidas pelos NPCs espalhados pelo mundo.
- 🧑‍🤝‍🧑 **Multiplayer online** para jogar com um amigo usando WebRTC e PeerJS.
- 📱 **Controles para celular**, incluindo joystick virtual e botões de ação. A experiência mobile está em beta.
- 🎨 **Sprites pixel art** para o personagem, inimigos, chefe e NPCs.

## 🕹️ Como jogar

### No computador

| Ação | Controle |
| --- | --- |
| Mover | `W` `A` `S` `D` ou setas |
| Atacar | `Espaço` ou clique |
| Interagir com o mundo | `E` |
| Usar dash | `Q` |
| Ativar/desativar o Senso | `Y` |

### No celular

Use o joystick virtual para se mover e os botões na tela para atacar, interagir e usar habilidades.

## 🚀 Executar localmente

O jogo não precisa de instalação ou etapa de compilação:

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Clique em **COMEÇAR O JOGO** e boa aventura! 🎉

Para jogar multiplayer, é necessário estar conectado à internet para carregar o PeerJS e estabelecer a conexão WebRTC.

## 🧰 Tecnologias

- HTML5 e Canvas
- CSS
- JavaScript
- PeerJS / WebRTC para o multiplayer
